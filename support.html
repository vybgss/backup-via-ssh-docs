Backup via SSH - Support

If you're experiencing issues with Backup via SSH or have any questions, you're in the right place. Below, you'll find ways to get help or contact us for support. We're here to assist you and ensure you get the best experience backing up your servers.

Frequently Asked Questions (FAQ)

  • 1. How do I add a server to backup?
    Click the "Add Server" button in the toolbar and enter your server details: hostname or IP address, SSH username (default: root), port (default: 22), optional SSH key path, and the directories you want to backup (one per line). Then click "Add Server" to save the configuration.
  • 2. What authentication methods are supported?
    Backup via SSH supports SSH key authentication only. You can specify the path to your private key (e.g., ~/.ssh/id_rsa) and indicate if it requires a passphrase. Password-based authentication is not supported for security reasons.
  • 3. Where are my backups stored?
    All backups are stored locally on your Mac in the ~/Backup via SSH/ directory. Each backup is saved as a ZIP archive with the format {hostname}_{timestamp}.zip. You can access this folder by clicking the "Open Backups Folder" button in the app.
  • 4. Can I backup multiple servers at once?
    Yes! Click the "Backup All" button in the toolbar to run backups for all configured servers simultaneously. The app uses parallel processing to efficiently backup multiple servers at the same time.
  • 5. How do I export and import my server list?
    Click the gear icon in the toolbar and select "Export Servers" to save your server configurations as a JSON file. To import, select "Import Servers" and choose a previously exported file. This is useful for migrating settings between machines or sharing configurations with team members. Note: SSH keys and passphrases are never exported for security reasons.
  • 6. What happens if a directory doesn't exist on the server?
    The app will continue backing up other directories even if some don't exist.
  • 7. I'm getting "Permission denied" errors. What should I do?
    Test your SSH connection manually with ssh -i ~/.ssh/id_rsa user@hostname to diagnose the issue.
  • 8. Can I stop a backup in progress?
    Yes, you can click the "Stop" button on any server card to cancel an in-progress backup. The app will safely terminate the backup process and clean up any temporary files.
  • 9. How does the app handle SSH keys with passphrases?
    When you enable "Passphrase Required" for a server, the app will prompt you for the passphrase when you start a backup. It uses isolated ssh-agent sessions for security and never stores your passphrase.
  • 10. What directories should I backup?
    Common directories to backup include:
    • /var/www - Web server files
    • /etc/nginx or /etc/apache2 - Web server configurations
    • /etc/letsencrypt - SSL certificates
    • /home - User home directories
    • Database dumps or application-specific directories
    Customize the directory list based on your server's specific needs.
  • 11. Does the app work with all server types?
    Backup via SSH works with any Linux or Unix-based server that supports SSH access and has rsync installed (which is standard on most systems). This includes Ubuntu, Debian, CentOS, RHEL, and other popular distributions.
  • 12. What are the system requirements?
    The app uses built-in macOS tools like rsync and ssh, so no additional software installation is required on your Mac.
